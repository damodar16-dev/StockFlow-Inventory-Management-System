📦 StockSphere

Inventory Management System

StockSphere is a modern Inventory Management System developed using Spring Boot, Spring Security, Thymeleaf, Bootstrap and MySQL.

🚀 Features

Product Management

Add, edit, delete and search products easily.

Category Management

Organize products into different categories.

PDF Export

Generate inventory reports in PDF format.
